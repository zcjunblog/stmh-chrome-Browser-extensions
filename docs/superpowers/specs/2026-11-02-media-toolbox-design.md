# 视听魔盒 MV3 更新方案

用户将四个功能的升级方案交给维护者决定。保留「视听魔盒」身份，提供可离线使用的实际工具，供日常使用及个人项目展示。

## 方案与取舍

- 仅迁移 MV3：无法恢复已变更用途的音乐、壁纸、导航站点，不采用。
- 更换第三方聚合 API：仍依赖未知服务的授权与稳定性，不采用。
- **采用本地工具 + 公开网站入口**：核心功能无需服务端；在线内容通过明确的网站链接打开。

## 四个功能

1. 音乐：选择或拖入多个本地音频，歌单切换、循环、播放速度与音量控制，按文件信息记忆进度。重新打开扩展需要重新选择文件，文件本身不上传、不持久化。
2. 视频：本地文件及 HTTP(S) 媒体直链播放，速度控制、进度恢复、画面截图。支持范围受浏览器解码能力、媒体服务器限制；不是网页地址解析器，不绕过会员、DRM 或广告。
3. 壁纸：内置原创程序绘制风格，预览并导出 1080p、2K、4K PNG，不依赖图片接口。浏览器保存下载，不修改系统桌面。
4. 导航：音乐、视频、壁纸等常用站点入口，自定义链接、搜索和删除；右键收藏当前网页，收藏存在本机。

## 工程与交互

- 原生 HTML/CSS/ES modules；扩展源码继续放在 `stmh-chrome/`，无需构建。
- MV3 service worker；仅 `storage`、`contextMenus`、`activeTab` 权限，无常驻网页注入，无全站访问权限。
- 小弹窗作为四个工具的入口，完整工具页在独立标签中运行，关闭弹窗不终止音乐。
- 暖白底、深色文字、橙色强调，支持系统深色模式与窄屏；语义化按钮、表单标签与键盘焦点。
- 所有配置为本机存储，无统计、无上传；仅主动点击网站/打开媒体直链才访问外网。
- 清除当前目录中已失效的旧 iframe、网页注入和旧 CRX；保留 Git 历史。README 顶部说明新版功能，提供真实截图、安装与打包方法、隐私和兼容性边界。

## 验收

Node 测试 URL 校验、收藏去重/上限、文件进度键和恢复边界；Playwright 在真实 Chromium 加载打包后的扩展，测试持久化收藏、本地音频/视频解码与播放、重新选文件后的进度恢复、PNG 导出尺寸、无网页脚本错误。安装包为可复现 ZIP，并提供 SHA256 校验。
