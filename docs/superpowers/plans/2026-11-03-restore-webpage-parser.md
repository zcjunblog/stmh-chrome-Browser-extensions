# 恢复网页一键解析

用户明确要求搜索免费解析服务并内置插件，恢复原插件在视频网页上的一键操作。延续用户委托，不再改变为其他产品方向。

1. 筛选服务并以实际媒体画面和播放进度验证。采用 TXNP 公开播放器入口，已用爱奇艺公开预告片和 B 站公开视频验证；不声明其他平台和付费内容都可播放。证据见 `docs/parser-services.md`。
2. `parser.mjs` 集中校验平台播放页和构造第三方链接；仅发送规范化播放地址，去掉无关查询参数。先运行 Node 失败测试，再实现。
3. 恢复视频网页悬浮按钮、右键解析、弹窗一键解析。外部播放器在独立标签中打开，不把外部脚本载入扩展，不收集 Cookie。新增可手动粘贴网页地址的解析页；本地播放器保留为补充功能。
4. 用打包后的真实扩展验证：识别正确网页、SPA 切换、按钮点击打开正确第三方 URL、非播放页不展示按钮；通过测试服务器路由做离线 CI，不在 CI 消耗公共解析服务。实际在线播放另行人工/浏览器低频验收。
5. 更新版本、README、隐私与截图，经代码审查和 CI 后提交发布。
