# 第三方解析服务核验

核验日期：2026-11-03。此记录是有限样本的实际观察，不代表持续在线、平台授权或所有内容可用的保证。

## 已内置：TXNP 弹幕播放器

- 服务方入口：<https://art.txnp.cn/>。空参数首页显示「上方链接为接口，可复制后自行调用」，公开提供 `https://art.txnp.cn/?url=` 格式。
- 无需注册、付费或 API Key 即可打开并播放本次公开样本。仅通过公开页面正常使用，没有调用隐藏接口、仿冒账号或绕过服务访问限制。
- 解析在服务方独立标签页完成，扩展不嵌入第三方脚本，不读取 Cookie；只在用户主动点击时发送规范化视频页网址。

| 公开样本 | 来源 | 浏览器实测 |
| --- | --- | --- |
| 《民宿惊魂》终极预告 | [爱奇艺公开预告片](https://www.iqiyi.com/v_1fb7mjixsos.html)，从[电影频道「大片预热」](https://www.iqiyi.com/dianying_new)进入 | 出现匹配预告画面；1920×1080，约52秒，播放时间推进 |

未用会员受限视频验证，不作会员解锁、去广告、全平台支持或永久可用承诺。插件识别腾讯视频、优酷、芒果TV播放页，只表示可把地址交给该服务，不表示完成这些平台的播放验证。免费线路不可用时，不会自动偷偷转发到其他解析服务。

另以真实扩展在真实爱奇艺播放页执行完整流程：网页返回 200 → 点击悬浮按钮 → 新标签接收到相同播放地址 → 出现 1920×1080、52秒的视频并推进播放时间。浏览器可能限制自动播放，需要用户在解析页点击播放。

## 自动化验证边界

Node 测试覆盖播放页匹配、相似恶意域名拒绝、查询参数清理与解析地址编码。Chromium 集成测试加载真实 ZIP，在受控视频站页面上触发实际内容脚本，并拦截第三方边界验证新标签页地址；CI 不会对公共解析服务发起批量健康检查。

实际在线播放证据与本地集成测试分开记录，不能把边界路由测试当作服务方播放成功。
